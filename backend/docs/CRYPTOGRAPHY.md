# ZeroLeak — Cryptography & Secure Question Storage

## 1. Overview

ZeroLeak protects examination question content using authenticated encryption,
SHA-256 integrity hashing, and Merkle-tree based exam integrity verification.

The system protects sensitive question information such as:

- Question text
- Options
- Correct answer
- Correct answer index

The encryption key is stored only in the backend environment and is never
returned to clients.

---

## 2. Security Architecture

The question security lifecycle is:

Professor creates Batch
        ↓
Draft Batch remains editable
        ↓
Admin approves Batch
        ↓
Sensitive question content is encrypted
        ↓
SHA-256 integrity hash is generated
        ↓
Encrypted Question stored in MongoDB
        ↓
Questions selected for Exam
        ↓
Question hashes form a Merkle tree
        ↓
Merkle root stored with Exam
        ↓
Student requests Exam
        ↓
Question integrity verified
        ↓
Merkle root verified
        ↓
Question decrypted on backend
        ↓
Safe question data returned to Student

## 3. Encryption

### Algorithm

AES-256-GCM is used for question-content encryption.

AES-256-GCM provides:

- Confidentiality
- Authentication
- Tamper detection

Each encryption operation generates a fresh random 12-byte IV.

The authentication tag generated by GCM is stored together with the
ciphertext.
